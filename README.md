# CampusTwin 🌱

**AI-Powered Sustainable Campus Digital Twin**

CampusTwin combines computer vision, simulated IoT sensors, deterministic rule-based detection, and a local LLM to identify potential campus inefficiencies and recommend corrective actions.

### Key Features
- **Computer Vision:** YOLO-based people and object detection using a camera.
- **IoT Simulation:** Simulated temperature, humidity, power, AC, lighting, and water-leak readings.
- **Hybrid Intelligence:** Combines deterministic rules with AI-generated explanations and recommendations.
- **Local AI:** Uses Ollama and Llama 3.2:3B for local inference.

## Requirements
- Python 3.12
- [Ollama](https://ollama.com/)
- [ngrok](https://ngrok.com/) (for remote camera access)

## Setup & Execution

Run each component in a **separate terminal**.

### 1. Start Ollama

```bash
ollama serve
```

### 2. Download the AI Model

```bash
ollama pull llama3.2:3b
```

### 3. Start the CampusTwin Backend

```bash
cd "/Volumes/Research/0x_projects/Campus Twin"
.venv312/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

### 4. Start ngrok (Optional)

Required for accessing the camera interface remotely, such as from an iPhone.

```bash
ngrok http 8000
```

Open the HTTPS forwarding URL generated by ngrok and append `/camera`.

### 5. Alternative Server Entry Point

If you use `server.py` instead of the Uvicorn command above, open another terminal and run:

```bash
cd "/Volumes/Research/0x_projects/Campus Twin"
.venv312/bin/python server.py
```

**Note:** Use the entry point appropriate to your setup. Do not start both backend commands simultaneously unless they are configured to use different ports.

## Limitations
- IoT readings are simulated; they are not measurements from physical campus sensors.
- AI recommendations require human verification.
- Energy savings are estimates, not verified real-world results.
